# Brand

The buildwith.uz mark is two overlapping rounded tiles with a lapis square where they meet.
The wordmark is `buildwith` in ink with `.uz` in lapis.

| File                                                                                     | Use                                           |
| ---------------------------------------------------------------------------------------- | --------------------------------------------- |
| `lockup.svg`                                                                             | Mark + wordmark, for light backgrounds        |
| `lockup-dark.svg`                                                                        | Mark + wordmark, for dark backgrounds         |
| `mark.svg` / `mark-dark.svg`                                                             | The mark alone, 64 × 64 grid                  |
| `favicon.svg`                                                                            | Mark that follows the browser's colour scheme |
| `png/icon-192.png`, `png/icon-512.png`, `png/apple-touch-icon.png`, `png/favicon-32.png` | App icons                                     |
| `png/github-avatar.png`                                                                  | GitHub organisation avatar                    |
| `png/github-social-preview.png`                                                          | Repository social preview (1280 × 640)        |

Colours come from the design tokens in `packages/ui/src/tokens.css`:
ink `#1F1E1C` (dark theme `#ECE9E3`), lapis `#2350A0` (dark theme text `#7FA6F0`), paper `#FAF8F4` (dark `#151413`).

Keep clear space of at least one tile radius around the mark. Don't recolour it, add effects, or set the
wordmark in another typeface.
